# So sánh Incognito Mode và Dedicated Profile

## Phần 1: So sánh

| Tiêu chí | Incognito Mode | Dedicated Profile |
|---|---|---|
| Cách ly dữ liệu | Tách phiên đăng nhập và cookie tạm thời; không cách ly hoàn toàn | Tách cookie, lịch sử, bookmark theo profile |
| Lưu trạng thái | Xóa cookie/phiên khi đóng hết cửa sổ ẩn danh | Giữ đăng nhập, lịch sử, bookmark lâu dài |
| Hiệu suất làm việc | Nhanh để kiểm thử ngắn, phải đăng nhập lại | Thuận tiện làm việc hằng ngày, chuyển profile nhanh |
| Ưu điểm | Ít lưu dấu vết duyệt web trên máy | Quản lý tài khoản, tiện ích và tài liệu riêng |
| Nhược điểm | Mất phiên đăng nhập khi đóng; không phù hợp làm việc lâu dài | Cần tạo và quản lý nhiều profile |

**Lưu ý:** Bookmark được lưu thủ công trong chế độ ẩn danh có thể vẫn tồn tại trong profile gốc; thứ thường mất khi đóng ẩn danh là phiên đăng nhập và dữ liệu phiên.

## Phần 2: Lựa chọn

Dùng **3 Dedicated Profiles**:

- **Personal:** Tài khoản và dữ liệu cá nhân.
- **Work:** Tài khoản LMS, tài liệu và bookmark dự án.
- **Sandbox:** Tài khoản test, thử nghiệm và gỡ lỗi.

**Kết luận:** Dedicated Profile tối ưu hơn cho Dev vì tách tài khoản, giữ dữ liệu và không phải đăng nhập lại liên tục. Dùng Incognito khi cần kiểm thử phiên tạm thời.
